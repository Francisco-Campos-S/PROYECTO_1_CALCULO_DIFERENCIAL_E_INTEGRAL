# Proyecto 1 — Cálculo Diferencial e Integral

Repositorio general del **Proyecto 1** de la asignatura **Cálculo Diferencial e Integral**.

Este archivo es el README de la raíz. Describe el propósito del trabajo y el papel de cada grupo. **No sustituye** el README que cada equipo debe escribir dentro de su propia carpeta.

## Propósito

El proyecto reúne el trabajo de los cinco grupos del curso. Cada grupo resuelve y documenta un problema de cálculo diferencial e integral en su carpeta, de modo que el repositorio quede organizado, revisable y fácil de evaluar.

En conjunto, el repositorio permite:

- Separar el trabajo de cada equipo sin mezclar archivos.
- Identificar a los integrantes de cada grupo.
- Dejar por escrito el objetivo, el procedimiento y los resultados de cada proyecto.
- Consultar, desde este README general, dónde está el trabajo de cada uno.

## Recordatorio para los estudiantes

**Cada grupo debe crear un `README.md` dentro de su carpeta.** El README de la raíz solo explica el repositorio completo. El de cada proyecto explica el trabajo de ese equipo.

Colóquenlo así:

- Grupo 1: `GRUPO_1/README.md`
- Grupo 2: `GRUPO_2/README.md`
- Grupo 3: `GRUPO_3/README.md`
- Grupo 4: `GRUPO_4/README.md`
- Grupo 5: `GRUPO_5/README.md`

Ese README debe incluir, como mínimo:

1. **Título** del proyecto del grupo.
2. **Integrantes** (nombre completo de cada estudiante).
3. **Objetivo**: qué problema de cálculo diferencial o integral resuelven y para qué.
4. **Desarrollo**: límites, derivadas, integrales u otros conceptos usados, con el procedimiento claro.
5. **Resultados**: respuestas, gráficas, tablas o archivos generados.
6. **Conclusiones**: qué se obtuvo y qué se aprendió.
7. **Cómo revisar el trabajo**: qué archivos abrir y, si hay código, cómo ejecutarlo.

Completen también `INTEGRANTES.txt` en su carpeta. No modifiquen las carpetas de los otros grupos.
